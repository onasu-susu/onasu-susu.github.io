アップロード

    1 回に送れるのは合計 25MB までです。同じフォルダに同じ名前のファイルがあるときは、新しいファイルで置きかえます。

    アップロードの設定

    アップロードは、自分の Google アカウントで動かす受付（Google Apps Script）を通して GitHub に保存します。GitHub のトークンは受付の中にだけ置き、このサイトには出しません。

    1. GitHub で fine-grained トークンを作る（リポジトリは onasu-susu.github.io だけ、権限は Contents: Read and write）
    2. script.google.com で新しいプロジェクトを作り、uploader.gs の中身を貼り付ける
    3. 「プロジェクトの設定 → スクリプト プロパティ」に、GITHUB_TOKEN（1 のトークン）と UPLOAD_KEY（下の合言葉）を追加する
    4. 「デプロイ → 新しいデプロイ → ウェブアプリ」で、実行するユーザーを「自分」、アクセスできるユーザーを「全員」にしてデプロイし、出てきた URL を下に貼る

    合言葉（UPLOAD_KEY）：…

    ※ 合言葉は資料のパスワードから作られます。パスワードを変えたら、スクリプト プロパティの UPLOAD_KEY も新しい合言葉に入れかえてください。
