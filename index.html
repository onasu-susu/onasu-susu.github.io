組み込み・IoT

M5Stack × Firebase ワンタイムQR認証

M5Stack の画面に表示した QR コードをスマホで読みとり、Google アカウントでログインして本人確認をするシステムです。QR コードの中のトークンは 1 回しか使えず、同じアカウントで 2 回認証することもできません。認証の記録は Cloud Firestore に保存します。

  • M5Stack
  • Firebase Hosting
  • Firebase Authentication
  • Cloud Firestore
  • JavaScript
  1. M5Stackワンタイムの QR コードを表示
  2. スマホQR を読みとってページを開く
  3. Google ログインFirebase Authentication
  4. チェックトークンが正しい・未使用か確かめる
  5. 記録Firestore に保存して、トークンを使用済みに

大学での学び

プログラミング

コンピュータがメモリをどう使っているのかといった、ふだんは見えない「裏側」に近いところまで意識してプログラムを書いています。AI の授業では、お店のレビュー文を読ませて「ほめているか、けなしているか」をコンピュータに見分けさせる仕組みも作りました。

  • C
  • Python
  • AI

アルゴリズムとデータ構造

たくさんのデータを速く並べかえる方法や、地図アプリのように「いちばん近い道」を見つける方法など、コンピュータに上手に仕事をさせるための考え方を、実際にプログラムを書きながら学んでいます。

  • 並べかえ
  • 道さがし

微分積分

電卓が複雑な計算の答えを一瞬で出せるのは、むずかしい計算を簡単な足し算・かけ算の組み合わせで近づけているからです。そんな「むずかしいものを、扱いやすい形に近づける」考え方や、山の斜面のように方向によって変わり方がちがうものを調べる方法を学んでいます。

  • 近似
  • 変化をとらえる

波動・物理数学

ばねでつながったおもりを 2 個、3 個と増やしていき、最後に数えきれないほど並べると、ギターの弦や音のような「波」になります。その様子を数学で追いかけて、波がどう伝わるのかを考えています。

  • 振動
  • 波

数学・理論

正しい理屈の組み立て方や、コンピュータがプログラムの文をどう読みとるのか、音をいろいろな高さの音に分ける方法（音楽アプリのイコライザーにも使われています）など、情報の世界を支える数学を学んでいます。

  • 論理
  • ことばと計算
  • 音の分解

情報システム・認知科学

コンピュータの仕組みに加えて、人の考え方のクセも調べています。たとえば、先に見た数字に引っぱられて判断が変わってしまう「アンカリング効果」を実験で確かめ、集めたデータを分析しました。

  • コンピュータの仕組み
  • 人の心理
  • データ分析
